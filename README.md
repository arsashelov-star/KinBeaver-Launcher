## Что это?
Умный лаунчер Minecraft, который сам подбирает JVM, RAM и Java-флаги. Забудьте о настройках — просто играйте!

---

## Как он работает?
* **Smart Boost:** анализирует вашу систему и автоматически настраивает параметры запуска.
* **Crash Parser:** переводит ошибки игры на человеческий язык («Не хватает памяти!» или «Конфликт модов»).
* **Каталог Modrinth:** позволяет устанавливать моды одним кликом прямо из лаунчера.
